- URL: `https://burger-stack-421794940461.asia-northeast1.run.app`
- 種別: **無料枠**(超過で課金。カード必須)
- リージョン: asia-northeast1(東京)

## 計測結果: 取り下げ

2026-09-22 の最初の計測で次の値を得たが、**すべて無効である**。

| エンドポイント | p50 |
|---|---|
| `GET /meta` | 44ms |
| `GET /up` | 44ms |
| `GET /shops` | 45ms |

アプリがデプロイされておらず、**Cloud Run の既定のプレースホルダー画面**を測っていた。
応答は `content-type: text/html` で、本文は `<title>Placeholder | Cloud Run</title>` だった。

### 気づいた経緯

不自然さは数字に出ていた。`/meta`(DB を使わない)と `/up`(DB に ping する)の
p50 が同じ 44ms で、**DB 往復の差分が 0ms** になっていた。他の 3 ホストでは
175〜385ms の差が出ている。

決め手は写真のアップロードで、**認証トークンが空なのに 200 が返った**ことだった。
存在しないはずの経路にも同じ応答を返している = すべて同じページ、と判明した。

### 再発防止

`scripts/bench/latency.sh` に事前確認を追加した。計測を始める前に 1 回叩き、
`content-type` が `text/html` なら警告を出す。

```text
事前確認: HTTP 200 / text/html; charset=utf-8
  ★ HTML が返っている。API のエンドポイントなら、アプリではなく
     プラットフォームの既定ページを測っている可能性が高い。中身を確認すること。
```

**教訓**: ステータスコードだけを見て計測してはいけない。速すぎる結果こそ疑う。
