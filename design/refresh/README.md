# Burger Stack 全体デザイン / 2026年9月

編集用ファイル: `../files/burgerstack-refresh-2026-09.penpot`

既存18ページを残し、`2026-09 Burger Stack / PC` と `2026-09 Burger Stack / モバイル` に主要10画面ずつを追加しています。新しい提案はこの2ページから確認してください。既存ページの認証・管理・投稿フォームなどは従来案を参照できます。

- お店一覧、ハンバーガー一覧、レビュー一覧
- お店詳細、ハンバーガー詳細、レビュー詳細
- マイページ、未投稿のマイページ
- 接続済みのアプリ
- Burger Stackについて

白・黒・マスタード色と写真を中心に構成。サービスロゴは現在の線画を採用し、評価のバーガーとは用途を分けています。ヘッダーに紹介ページへのリンクを置き、食べた日・投稿日・店舗名を区別しました。検索・並び替え、関連ページへのリンク、未投稿の「何も食べていません」、連携アプリの日本語説明を含みます。紹介文はPRにいただいた文章を元にしています。

写真は以前ダウンロードした素材を使ったデザイン用サンプルです。カードの店名・商品名・評価・件数は架空の見本で、写真の実際の店や商品との対応を示しません。

## 編集・確認

ローカルPenpot: http://localhost:9001 。インポートから `.penpot` を読み込めます。文字・カード・評価・サービスロゴは編集可能な図形です。PCは1280px、スマートフォンは375pxを基準としています。固定配置の画面案で、レスポンシブの自動配置やクリックできるプロトタイプではありません。

`previews/*.png` はPenpotのexporterから書き出した確認画像です。`boards.json` はローカル作業ファイルとボードIDの対応です。元の18ページを含む既存案は上書きしていません。

再生成スクリプトは `../scripts/build_burgerstack_refresh.py`。既存案をインポートした別ファイルに対して実行します。`2026-09 Burger Stack / ` で始まるページのみ再生成します。

```sh
python3 design/scripts/build_burgerstack_refresh.py \
  --file-id <インポート先ファイルID> \
  --email <ローカルPenpotのメール> \
  --password-file <ローカルの非公開パスワードファイル>
```

秘密情報はこのディレクトリに保存しないでください。アプリ本体のfrontend/backendには変更を加えていません。

## 検証

`python3 design/scripts/validate_burgerstack_refresh.py` で、Penpotファイルの破損・20ボードの対応・主要文言・20枚のPNGのCRCと寸法・ギャラリーのリンクを確認できます。
