実装メモ
  • ・「レビューを書く」を出すかは、backend が返す(can_review)。却下されたショップでは出さない。審査中は、作った本人と管理者だけに出る(それ以外の人には、そのショップ自体を API が返さない)。
  • ・ショップの写真と、平均のバーガー・件数は、いまの API にない(ショップの詳細は、レビューの一覧だけ)。実装するなら、API に足す(ショップの一覧と同じ前提)。
  • ・状態の表示(審査待ち・却下と、却下の理由)は、backend が返した状態と理由をそのまま出す。ショップが見つからないときは、「売り切れです」の画面(states の見本)。
  • ・サインインしていない人には、「レビューを書く」を出さない(can_review は、サインインしていない人は常に false)。いまのアプリは、何も出さない。この見本の「サインインして、レビューを書く →」は、サインインの状態で決める、案(いまのアプリにはない)。
