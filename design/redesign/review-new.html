実装メモ
  • ・評価は、数字のボタン(ラジオボタンの集まり。role="radiogroup")で選ぶ。矢印キーで増減し、選んだ数字を大きく表示する。バーガーは、選んだ値の水位を見せるだけ(押せない)。段階の数と水位は、GET /meta の rating(min・max)から決める。frontend に 5 を書かない。最初に選ばれている値(いまのアプリは 3)は、実装のとき決める。
  • ・文字数のカウンターの上限(コメント 2000・バーガー名 100)は、いまの GET /meta にない(評価と写真の上限だけ)。出すなら /meta に足して、そこから取る。frontend に数字を書かない。出さないなら、カウンターをやめて、API のエラー文言だけにする。見本の数字は仮。
  • ・写真の 5MB・長辺の上限は、GET /meta の photo から取る(見本の数字は仮)。
  • ・エラーの文言(Comment is too long … など)は API が返したものをそのまま出す。API のエラーは、どの入力欄のものか分からない形なので、画面の上にまとめて出す。
