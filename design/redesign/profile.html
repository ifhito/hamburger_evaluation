実装メモ
  • ・「プロフィールを編集」は、backend が返す(can_edit。GET /users/:id)ときだけ出す。本人だけが true で、管理者でも他人のプロフィールは false。frontend は、閲覧者と持ち主の比較をしない。
  • ・メールアドレスは、API が本人の閲覧のときだけ返す。frontend は、返ってきたときだけ出す(他人の画面には出ない)。自己紹介は、誰にでも見える。文字は、HTML として解釈せず、改行だけを保って出す。
  • ・「接続済みのアプリ」は、本人のプロフィール(can_edit が true)だけに出し、OAuth の認可サーバーが無効なとき(API が 404)は、何も出さない。アプリの名前と、許可の範囲の説明文は、API が返したものをそのまま出す(frontend に、範囲の名前や説明を持たない)。いまの API の説明文は日本語だけ。英語の画面で英語にするには、API が言語に合わせて返す必要がある。
  • ・「解除」を押すと、確認(ダイアログ。「プロフィールの状態」の見本)のあとで、そのアプリは、すぐ使えなくなる。「もっと見る」は、次のページがある(X-Has-More)ときだけ出す。
  • ・「リンクをコピー」は、誰にでも出す(サインインしていなくても)。コピーできなかったときの見せ方は、「プロフィールの状態」の見本。
